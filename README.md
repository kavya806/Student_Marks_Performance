# Student Marks Performance Prediction

## Project Overview

This project predicts whether a student will pass or fail based on their academic performance.

## Features Used

- Attendance Percentage
- Homework Percentage
- Midterm Score
- Study Hours per Week

## Machine Learning Model

The project uses a Machine Learning classification model to predict student performance.

Models tested:
- Decision Tree Classifier
- Random Forest Classifier

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Streamlit

## Application

The trained model is connected to a Streamlit web application where users can enter student details and get a PASS or FAIL prediction.

## Project Workflow

Dataset → Data Preprocessing → EDA → Train/Test Split → Model Training → Model Evaluation → Model Saving → Streamlit Deployment
